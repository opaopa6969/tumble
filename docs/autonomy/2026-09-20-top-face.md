## 仮説と判断

面の判定は姿勢だけで決まる純粋な幾何であり、ソルバーに触れずに追加できる。
箱の面法線は body-local 軸そのものなので、`±x, ±y, ±z` を `body.q` で世界座標へ
回し、`up` との内積が最大のものを選べばよい。戻り値に内積 (`alignment`) を含めると、
「辺で立っている骰子を誤読しない」判定をホストが自分で書ける。

M4 全体（壁のシャッフル・捨て牌）ではなく、その中で最も小さく自己完結した
「上面を読む」だけを選んだ。既存コードパスを一切変更しない追加なので、
revert が機械的に成立する。骰子の目の割り当ては盤面規約であり、
エンジンの関心事ではないと判断してホストに委ねた。

同着（辺・角で釣り合う姿勢）の扱いは仕様の選択肢だが、止まらずに
「軸番号の小さい方、次に `sign:+1`」という固定走査順＋狭義改善判定を選び、
決定性（no `Math.random`、bit-identical）という house style を維持した。

## 実施内容と終了要件

- `topFace(body, up = [0,1,0])` を export し、`{ axis, sign, normal, alignment }`
  を返す。コンストラクタは長さ非0の quaternion をすべて受け入れるが、
  内部の `q.rot` は単位 quaternion 前提の式で、`|q| ≠ 1` では回転にならない
  （定数倍ではなく別の写像になる）。そのため `topFace` は先頭で `q.norm` し、
  同じ姿勢を表す quaternion なら長さによらず同じ面を返す。
- 不正入力（body 欠落 / 3要素の quat / NaN / 長さ0の up）は既存ガードと同じ
  `TypeError` / `RangeError`。
- 恒等・180°・90°回転、任意 `up`、非正規化 quat（純スカラーの退化例と、
  x軴30°を 2 倍した非退化例の両方）、同着の決定性、状態不変、
  静止した立方体で `alignment > 0.99` かつ6面中の最上面と一致することを回帰検査する
  （最上面の照合は index.js のコードを再利用せず、テスト側で回転を展開して独立計算）。
- README / DESIGN に API と M4 における位置づけ（M4 自体は planned のまま）を記載する。
- `node test.mjs` 215件成功、`node --check`、`git diff --check`、PR CI 成功。
- 独立 Judge の accept 後に Finalizer が merge し、issue #37 の close を確認する。

対象外は骰子の目（pip）割り当て、sphere collider、M4 の残り
（壁シャッフル・捨て牌）、既存物理の変更である。
取り消す場合は merge commit を `git revert -m 1` する別 PR を検証・merge し、
issue #37 を reopen する。
